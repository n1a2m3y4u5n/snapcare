🎤 음성 명령 동등 채널

모든 화면 하단에 상시 노출되는 마이크 버튼은 동등한 진입로로 작동한다. 터치로 카드를 누르는 대신 다음과 같이 음성으로 동일한 흐름을 실행할 수 있다.

"사진" / "찍기"
→ 카메라 분기
"약 알람" / "오늘 약"
→ 알람 분기
"공유" / "의사"
→ 공유 분기

전체 흐름에서 사용자가 텍스트를 읽거나 입력해야 하는 단계는 존재하지 않는다.
터치와 음성은 동등한 1차 입력 채널이며, 어느 한 채널만으로도 모든 흐름이 완결된다.
