시각 자료 8

AST 트리 변환

DSL 문자열 → 재귀 하강 파서 → 추상 구문 트리

입력 DSL
\three_times_daily{\pill_bottle{\time_morning}}
재귀 하강 파싱
↓
OPERATOR
three_times_daily
children[0]
HEAD
pill_bottle
slot[0]
MODIFIER
time_morning
각 노드 구조
@dataclass
class Node:
    name: str
    kind: str      # head | modifier | operator
    children: List["Node"] = field(default_factory=list)
OPERATOR · 외부 작용
HEAD · 의약품
MODIFIER · 맥락

파서는 자신을 재귀 호출하며 트리를 구성한다.
operator는 자식을 1개, head는 슬롯 0개 이상, modifier는 슬롯 내부에만 존재한다.
