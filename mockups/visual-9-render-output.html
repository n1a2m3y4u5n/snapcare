시각 자료 9

SIGIL 합성 결과 예시

DSL 입력 → 형태소 합성 → 픽토그램 PNG

예시 1 — 반복 + 시간대
입력 DSL
\three_times_daily{
  \pill_bottle{
    \time_morning
  }
}
· three_times_daily = 반복 연산자
· pill_bottle = 알약 두부
· time_morning = 아침 수식어
합성 결과
"아침에 알약을 하루 세 번 복용"
예시 2 — 금기 (부정 연산자)
입력 DSL
\no{
  \state_pregnant
}
· no = 부정 연산자 (overlay)
· state_pregnant = 임신 상태 두부
→ 대각선 두 줄로 금기 표현 (Dowse 2004)
합성 결과
"임산부는 복용 금지"

모든 자산은 흑색 단색 선화의 투명 배경 PNG로 일정 규격을 준수한다.
합성기는 알파 채널 기반 합성으로 임의의 배경 위에 겹쳐 그릴 수 있다.
